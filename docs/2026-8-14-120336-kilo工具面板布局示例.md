## 布局流向说明
1. **顶层横向分割**
- 左栏：固定宽度侧边导航，垂直Tab列表；点击任意导航项，**替换右侧全部内容**。
- 右栏：占剩余全部宽度，可纵向滚动的配置表单面板。

2. **右侧面板内部纵向层级（从上往下线性流）**
```
模块大标题
├─顶层全局开关（复选框 + 描述文本 + 链接）
├─【子标签按钮组】切换子权限视图（读取/写入/删除/MCP…）
├─全局限制表单行（label + input输入框）
├─权限分组块1（图标+分组标题 → 多条复选框配置项）
├─权限分组块2（图标+分组标题 → 多条复选框配置项）
└─权限分组块N（标题 + 输入框 + 操作按钮）
```

## 组件层级树（线性缩进表示嵌套）
```
SettingPage(根页面)
├── LeftSidebar 左侧侧边栏
│   └── VerticalTabList 垂直Tab列表
│       └── TabItem[] 导航选项(图标+label，选中态高亮)
└── RightContentPanel 右侧内容容器(可滚动)
    ├── PageTitle 模块标题
    ├── GlobalConfigGroup 顶层开关组
    │   └── CheckboxItem(复选框+描述+link)
    ├── SubTabButtonGroup 子权限标签按钮组
    ├── LimitFormGroup 全局限制表单
    │   └── FormRow(label + Input)
    ├── PermissionGroup 权限分组容器（可多组重复）
    │   ├── GroupHeader(图标+分组名称)
    │   └── CheckboxItem[] 复选框配置行
    └── CommandWhiteListGroup
        ├── helpText说明文本
        ├── Input输入框
        └── Button 添加按钮
```
