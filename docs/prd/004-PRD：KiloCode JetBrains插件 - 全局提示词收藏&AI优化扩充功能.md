# PRD：KiloCode JetBrains插件 \- 全局提示词收藏\&AI优化扩充功能

## 一、可行性结论（前置核心判断）

**完全可以基于现有 KiloCode JetBrains 插件扩充实现，无底层改造障碍**

### 可实现依据

1. JetBrains 插件原生支持全局持久化存储（IDE 配置目录，跨项目全局），满足「全局提示词」存储需求；
2 Kilo 现有内置 LLM 调用链路可复用，无需新增 CLI / 远端接口，直接复用现有模型请求能力做提示词优化；
3 插件可新增独立 ToolWindow 侧边面板、聊天输入框右键菜单、斜杠命令，多入口操作提示词；
4 原地编辑、原地 AI 优化仅需新增弹窗 / 内嵌编辑组件，复用插件现有文本编辑、流式输出 UI；
5 无冲突：功能独立模块，不改动原有会话、RepoWiki、文件上下文核心逻辑，低侵入扩充。

### 唯一约束

插件无独立全局文件目录权限也可解决：使用 JetBrains 官方持久化 API 存储（IDE 全局配置目录，系统固定路径，跨项目自动读取），无需自定义系统文件夹读写权限。

## 二、产品整体需求

### 1 核心能力范围

1 **全局提示词库**
所有收藏提示词跨项目、跨 IDE 窗口全局生效，存储在 JetBrains IDE 系统标准配置目录，不受当前仓库限制；
2 **多入口快速调用**
Kilo 聊天输入框唤起收藏提示词，一键插入输入框；
3 **原地操作能力**
每条提示词独立卡片，支持：原地查看完整内容、原地手动编辑、原地调用 AI 自动优化；
4 **AI 一键优化**
选中 / 打开提示词，调用 Kilo 现有 LLM，自动优化指令清晰度、结构化、适配代码场景，优化结果可覆盖 / 另存新提示词；
5 **分类管理**
支持自定义分类（代码生成、bug 修复、架构分析、commit 生成、Wiki 编写等），搜索过滤；
6 基础管理：新增、删除、重命名、复制、置顶、导出导入提示词库。

### 2 目标用户 \& 使用场景

1 高频开发者：反复复用固定开发提示词，无需每次重复输入；
2 团队复用：导出提示词库分享给同事导入；
3 提示词迭代：原始指令效果差，原地 AI 自动优化，不用复制到外部工具；
4 会话快速注入：打开会话直接插入收藏好的标准化提示词，提升 AI 输出质量。

#### 数据结构（持久化实体）

```kotlin
data class PromptItem(
    val id: String, // 唯一uuid
    val name: String, // 提示词名称（展示用）
    val category: String, // 分类，默认「通用」
    val content: String, // 原始提示词正文
    val createTime: Long,
    val updateTime: Long,
    val isTop: Boolean, // 是否置顶
    val tags: List<String> // 标签，用于检索

data class PromptCollectionState(
    val promptList: MutableList<PromptItem> = mutableListOf()
)
```

